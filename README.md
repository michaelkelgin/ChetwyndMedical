# Chetwynd Medical Staff Association

Public website for **ChetwyndMedical.ca** — the Chetwynd Medical Staff Association (MSA).

Visual structure and information architecture are adapted from the Prince George MSA site ([pgmedstaff.ca](https://pgmedstaff.ca/)), with Chetwynd branding (official MSA logo) and placeholder content clearly marked until real copy/assets are supplied.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4 + custom brand CSS

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
